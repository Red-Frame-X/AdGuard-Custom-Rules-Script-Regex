# ChromeOSを安全に手動更新する方法
ChromeOSの更新は、Googleが案内する設定画面から実行します。Croshの内部・診断用コマンドは、一般利用者向けの正式な更新手順としては案内されていません。

## 公式の実行手順

1. ChromebookをWi-Fiに接続します。
2. 画面右下の時刻を選択し、**設定**を開きます。
3. 左下の**ChromeOSについて**を選択します。
4. **アップデートを確認**を選択します。更新が見つかると自動的にダウンロードされます。
5. ダウンロード完了後、表示された場合は**再起動**を選択します。

`autest`は一般利用者向けの公式ヘルプに記載された更新方法ではないため、本書では推奨しません。更新できない場合は、端末の自動更新期限（AUE）、管理対象端末の更新ポリシー、空き容量、ネットワークを確認します。

## アップデート時にエラーが発生する場合

Google公式ヘルプでは、**システムアップデートでエラーが発生する場合**または**アップデートをダウンロードできない場合**の対処として、次の順序が案内されています。

1. モバイルデータ通信を使用している場合は、Wi-Fiまたはイーサネットへ切り替えて再試行します。
2. Chromebookの電源をいったんオフにしてからオンにします。
3. 改善しない場合は、Chromebookのリセットを試します。
4. それでも解決しない場合は、ChromeOSの復元を検討します。

このうち、Googleは別の公式ヘルプで、Chromebookの問題を解決する手段として**ハードウェアのリセット（ハードリセット）**を案内しています。ほとんどのChromebookでは、端末の電源を切り、**更新（Refresh）キーを押したまま電源ボタンを押し、起動後に更新キーを放す**手順です。

ハードウェアリセットはキーボードやタッチパッドなどのハードウェアを再起動する操作であり、Powerwashとは異なります。アップデートエラー専用の修復機能ではありませんが、通常の再起動やネットワーク確認で改善しないシステム上の問題に対するトラブルシューティングとして試すことで、結果としてアップデートが正常に進む場合があります。

> [!IMPORTANT]
> Googleは、ハードウェアリセットを**他の方法で問題を解決できなかった場合にのみ試す**よう案内しています。また、機種によって手順が異なり、`Downloads`フォルダ内のファイルが一部削除される可能性があります。実行前に必要なローカルファイルをバックアップし、必ず対象機種の公式手順を確認してください。
