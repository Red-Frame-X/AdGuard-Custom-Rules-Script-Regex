# NG Word Regex for ChMate

Android用5ちゃんねるブラウザChMateの「NGワード」で使用するJava正規表現集です。

## 登録手順

1. [`NG Word Regex for ChMate.txt`](NG%20Word%20Regex%20for%20ChMate.txt)を開きます。
2. 目的に合う正規表現を1件ずつコピーします。
3. ChMateのNG設定で「NGワード」を追加し、「正規表現」と「非表示」を有効にして貼り付けます。
4. 意図した投稿だけが非表示になるか確認してから常用します。

複数の式を一度に導入すると、どの式が誤検出したか特定しにくくなります。まず少数の式で試し、必要に応じて追加してください。文字範囲や語句を広く扱う式は、通常の投稿も非表示にする可能性があります。
