# NG Word Regex for ChMate

Android用5ちゃんねるブラウザChMateのNG設定で使用する正規表現集です。特定の語句や投稿パターンをまとめて判定するための個人用設定であり、5ちゃんねるやChMateの公式フィルタではありません。

## 登録手順

1. [`NG Word Regex for ChMate.txt`](NG%20Word%20Regex%20for%20ChMate.txt)を開きます。
2. 目的に合う正規表現を1件ずつコピーします。
3. ChMateのNG設定でNGワードを追加し、正規表現として登録します。
4. 必要に応じて非表示設定を有効にし、意図した投稿だけが対象になることを確認してから常用します。

## 注意点

複数の式を一度に導入すると、誤検出した式を特定しにくくなります。まず少数の式で試し、必要に応じて追加してください。

文字範囲、任意文字、繰り返し、選択肢などを広く指定する正規表現は、想定外の通常投稿にも一致する可能性があります。NG対象を増やす場合は、式を単純に広げるより、実際の投稿例で一致範囲を確認しながら条件を追加することを推奨します。

ChMateのUIやNG機能の挙動はバージョンによって変わる可能性があります。READMEの画面名と実際のアプリ表示が異なる場合は、使用中のChMateのNG設定画面を優先してください。
